# Survey Matcher MVP

نسخة أولى تجريبية لتجميع الرفع المساحي مع اللوحة.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح رابط Vite المحلي.

## الموجود حاليًا

- قراءة ملف SDR/CSV/TXT بصيغة نصية عامة (heuristic parser)
- قراءة DXF وعرض LINE / POLYLINE / LWPOLYLINE / CIRCLE / ARC
- عرض نقاط الرفع فوق اللوحة
- Zoom / Pan / Fit
- إخفاء/إظهار الرفع واللوحة
- البحث عن Point
- فحص أولي لنطاق الإحداثيات
- تصدير DXF للنقاط

## ملاحظة مهمة عن SDR وDWG

صيغة SDR تختلف حسب الجهاز/الإصدار، لذلك يجب اختبار Parser على ملف SDR حقيقي من المستخدم.

رفع DWG موجود في الواجهة، لكن قراءة DWG الفعلية تحتاج محرك DWG على Backend أو تحويل موثوق إلى DXF. لن ندعي دعم DWG الكامل قبل اختبار محرك مناسب.

## المرحلة التالية المقترحة

1. إضافة ملفات SDR/DWG/DXF الحقيقية.
2. بناء Parser SDR مطابق للصيغة الفعلية.
3. إضافة 2-point / 3-point alignment.
4. إضافة Move / Rotate / Scale.
5. دمج نقاط الرفع داخل DXF الأصلي مع الحفاظ على كل الـLayers والـBlocks.
6. QC وتقرير فروق E/N/Z.
7. إضافة Backend لمعالجة DWG.
